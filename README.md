<h1 align="center">linpkg</h1>
<p align="center">linpkg is a bulk package installer for major Linux distributions.</p>

### Features

- Automatic script generation based on selected package manager and packages.
- WIP: Automatic polling on the database to confirm package availability.
- Up to date packages due to the nature of Linux install commands.

### Developers
This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

1. Get the requirements
    ```bash
    pnpm install
    ```
2. Start the development server
    ```bbash
    pnpm dev
    ```
...Or similar based on your package manager of choice.
